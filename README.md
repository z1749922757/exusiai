# 新约能天使 · 展示页

明日方舟角色「能天使 / 新约能天使」的个人展示网页，包含双形态切换、角色档案、立绘画廊、故事摘录及语音播放。

## 访问地址

**https://z1749922757.github.io/exusiai/exusiai/exusiai.html**

## 功能

- **双形态切换** — 首屏右侧按钮可无缝切换新约能天使与原版能天使的视觉风格（立绘、背景、粒子颜色联动变化）
- **角色档案** — Tab 切换展示两张身份卡，含代号、本名、种族、出身、阵营等信息
- **形态画廊** — 网格展示 7 张立绘（新约精英一/二 + 原版初始/精英二 + 3 款皮肤），点击全屏预览，每次打开随机排列
- **故事碎片** — 三段档案摘录：苹果派物流的诞生、旧友评价、关于"新约"
- **语音彩蛋** — 10 条游戏原版语音，点击即播，附带进度条动画
- **页面进入音效** — 进入页面自动播放"戳一下"语音
