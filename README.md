# 明日方舟 - 能天使 (Exusiai) 角色展示页

一个关于《明日方舟》干员 **能天使** 的前端展示页面。

## 页面内容

- **角色主页** — 带粒子动效的全屏首屏，展示角色名称、称号与经典台词
- **干员档案** — 职业定位、稀有度、阵营、出身地、战斗风格、性格特点
- **天赋介绍** — 天使的祝福、企鹅物流的祝福
- **干员经历** — 以时间线形式呈现角色故事
- **语音台词** — 经典语音回顾
- **时装展示** — 各系列皮肤一览

## 技术栈

- 纯 HTML + CSS + JavaScript，无依赖
- CSS 渐变、卡片动画、响应式布局
- Canvas 粒子背景动效
- Intersection Observer 滚动动画

## 使用方式

直接在浏览器中打开 `exusiai.html` 即可。

## 预览

> 暗色主题 + 红金渐变配色，适配桌面端与移动端。
